An AI-powered web app that generates custom, job-specific cover letters instantly using Generative AI.

✨ Features

📝 User input (Role, Company, Skills, Experience)

🎨 Tone selection (Formal / Professional / Friendly)

🤖 AI-generated content

📄 Copy & Download option

🔐 Input validation

🛠️ Tech Stack

Frontend: HTML, CSS, JavaScript
Backend (Optional): Python (Flask)
AI: Gemini API / OpenAI API
